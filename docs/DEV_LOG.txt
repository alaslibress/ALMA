Write-Cadence Rule
------------------
Append an entry whenever:
  - A library is added or removed.
  - A prompt template is non-trivially edited.
  - A phase contract changes.
  - A safeguard rule fires for the first time on a real run.
  - An eval run produces a meaningful number.
  - A wrong assumption is discovered.

Do NOT append for:
  - Trivial renames or formatting.
  - Routine commits without thinking change.

Target: 2-6 entries per active day. Final count by day 7: 25-40 entries.

[2026-04-26 18:00] [DECISIONS] [ARCHITECTURE]
What:     Introduced `JsonExtractor` to strip Markdown fences before Jackson

Why:      OpenAI chat models routinely wrap JSON in ```json ... ``` even when

[2026-04-26 18:00] [DECISIONS] [TOOLS]
What:     Jackson configured with `ParameterNamesModule` and the project
          compiles with `-parameters`.
Why:      Java records are bound by Jackson via their canonical constructor
          parameter names. Without `ParameterNamesModule` + `-parameters`,
          parameter names are erased at compile time and Jackson throws
          MismatchedInputException at the first record. Forcing
          `@JsonProperty` annotations on every field would clutter the
          beginner-readable surface area.
Impact:   build.gradle.kts adds `tasks.withType<JavaCompile> {
          options.compilerArgs.add("-parameters") }`. libs.versions.toml
          pins `jackson-module-parameter-names`. AlmaJackson factory
          builds the shared ObjectMapper:
          `JsonMapper.builder().addModule(new ParameterNamesModule()).build()`.
          plans/01-bootstrap.md and plans/03-llm-probe-blueprint.md updated.
Followup: NONE.
